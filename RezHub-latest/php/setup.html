User: root

4Available API Endpoints

Use these endpoints to connect your frontend with the database:

Authentication

POST /php/api/register.php
Register a new user
POST /php/api/login.php
Login user
POST /php/api/logout.php
Logout user
GET /php/api/user.php
Get current user info

Hotels & Bookings

GET /php/api/search.php?city=Mumbai&checkIn=...&checkOut=...&guests=2
Search hotels
POST /php/api/book.php
Create a new booking
GET /php/api/bookings.php?status=confirmed
Get user's bookings
POST /php/api/review.php
Submit a review

6Frontend Integration

Update your frontend JavaScript to call these API endpoints. Example:

// Search hotels
fetch('/php/api/search.php?city=Mumbai&checkIn=2026-03-20&checkOut=2026-03-25&guests=2')
    .then(r => r.json())
    .then(data => console.log(data));
